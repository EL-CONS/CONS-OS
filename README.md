## CONS-OS

> **_IN SOFTWARE, AS IN LIFE, LESS CAN BE MORE_** . <sub> Eric S. Raymond</sub>

## A retro operative system web simulator.

+ **Languages:** html, JavaScript, CSS
+ **Live Demo:** https://el-cons.github.io/CONS-OS/


## Terminal Commands

<table border="0">
  <tr>
    <td><strong>HELP</strong></td>
    <td>List all the available terminal commands</td>
  </tr>
  <tr>
    <td><strong>CONSFETCH</strong></td>
    <td>Display CONS-OS system specifications and ASCII logo</td>
  </tr>
  <tr>
    <td><strong>ABOUT</strong></td>
    <td>Show system and author information</td>
  </tr>
  <tr>
    <td><strong>LS</strong></td>
    <td>List all accessible files and external links</td>
  </tr>
  <tr>
    <td><strong>CAT &lt;file&gt;</strong></td>
    <td>Print file contents directly to the terminal buffer</td>
  </tr>
  <tr>
    <td><strong>OPEN &lt;app/link&gt;</strong></td>
    <td>Open an application window or external link</td>
  </tr>
  <tr>
    <td><strong>JOURNAL &lt;file&gt;</strong></td>
    <td>Open a file inside the Journal editor</td>
  </tr>
  <tr>
    <td><strong>CLEAR</strong></td>
    <td>Clear the terminal output screen</td>
  </tr>
  <tr>
    <td><strong>RESET</strong></td>
    <td>Reset desktop state and reload active windows</td>
  </tr>
  <tr>
    <td><strong>SHUTDOWN</strong></td>
    <td>Power off the CRT monitor display</td>
  </tr>
  <tr>
    <td><strong>REBOOT</strong></td>
    <td>Trigger system reboot sequence</td>
  </tr>
  <tr>
    <td><strong>EXIT</strong></td>
    <td>Close the terminal window</td>
  </tr>
</table>

## How to Run Locally

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/EL-CONS/CONS-OS.git
cd CONS-OS
python3 -m http.server 8080
```
